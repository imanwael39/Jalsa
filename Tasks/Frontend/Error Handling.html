Objective

Implement a global error handler that catches all uncaught exceptions in the Angular application, logs them, displays a user‑friendly error message, and prevents the application from crashing.

Business Purpose

Users should never see a blank screen or cryptic error messages. Instead, they should see a friendly error page or notification, and the application should recover gracefully.

Technical Purpose

Extend Angular's ErrorHandler class to capture errors, send them to a logging service, and use AppStateService to show a notification or navigate to an error page.

  • Knowledge of AppStateService for notifications.

// core/services/global-error-handler.service.ts import { ErrorHandler, Injectable, inject } from '@angular/core'; import { AppStateService } from '../state/app-state.service'; @Injectable({ providedIn: 'root', }) export class GlobalErrorHandler implements ErrorHandler { private appState = inject(AppStateService); handleError(error: any): void { // Log the error to console console.error('Global error caught:', error); // Notify user let message = 'An unexpected error occurred. Please try again.'; if (error?.message) { message = error.message; } this.appState.addNotification(message, 'error'); // Optionally, log to a remote service (if ErrorLoggingService is available) // You can inject ErrorLoggingService here later. } }

// Enhanced handleError handleError(error: any): void { console.error('Global error caught:', error); let message = 'An unexpected error occurred.'; if (error instanceof Error) { message = error.message; } else if (typeof error === 'string') { message = error; } else if (error?.message) { message = error.message; } this.appState.addNotification(message, 'error'); // If it's a fatal error, navigate to an error page if (error?.isFatal) { // this.router.navigate(['/error']); } }

Step 1: Create ErrorLoggingService

// core/services/error-logging.service.ts import { Injectable, inject } from '@angular/core'; import { environment } from '../../../environments/environment'; import { HttpClientService } from '../api/http-client.service'; export type LogLevel = 'debug' | 'info' | 'warn' | 'error'; export interface LogEntry { timestamp: string; level: LogLevel; message: string; context?: any; stack?: string; userId?: string; sessionId?: string; url?: string; } @Injectable({ providedIn: 'root', }) export class ErrorLoggingService { private http = inject(HttpClientService); private logLevel: LogLevel = environment.logLevel || 'info'; private remoteLoggingUrl = environment.remoteLoggingUrl; log(level: LogLevel, message: string, context?: any) { const entry: LogEntry = { timestamp: new Date().toISOString(), level, message, context, stack: context instanceof Error ? context.stack : undefined, url: window.location.href, }; // Always log to console in development or if level is 'debug' if (!environment.production || level === 'debug') { console.log(`[${level}]`, message, context); } // Send to remote logging in production for error level if (environment.production && level === 'error' && this.remoteLoggingUrl) { this.sendToRemote(entry); } // Optionally store locally (e.g., localStorage or IndexedDB) } debug(message: string, context?: any) { if (this.shouldLog('debug')) { this.log('debug', message, context); } } info(message: string, context?: any) { if (this.shouldLog('info')) { this.log('info', message, context); } } warn(message: string, context?: any) { if (this.shouldLog('warn')) { this.log('warn', message, context); } } error(message: string, context?: any) { if (this.shouldLog('error')) { this.log('error', message, context); } } private shouldLog(level: LogLevel): boolean { const levels: LogLevel[] = ['debug', 'info', 'warn', 'error']; return levels.indexOf(level) >= levels.indexOf(this.logLevel); } private sendToRemote(entry: LogEntry) { // Send to remote logging endpoint (e.g., /api/log) this.http.post({ path: this.remoteLoggingUrl, method: 'POST' }, entry) .subscribe({ next: () => {}, error: (err) => console.error('Failed to send log to remote', err), }); } }

Step 2: Add Remote Logging URL to Environment

Step 2: Create Error Boundary Directive

Create a structural directive that catches errors in its view.

// shared/directives/error-boundary.directive.ts import { Directive, Input, TemplateRef, ViewContainerRef, OnDestroy } from '@angular/core'; @Directive({ selector: '[appErrorBoundary]', standalone: true, }) export class ErrorBoundaryDirective implements OnDestroy { @Input() set appErrorBoundary(condition: boolean) { if (condition) { // Show error template this.viewContainer.clear(); this.viewContainer.createEmbeddedView(this.fallbackTemplate); } else { // Show normal content this.viewContainer.clear(); this.viewContainer.createEmbeddedView(this.templateRef); } } @Input() fallbackTemplate!: TemplateRef<any>; constructor( private templateRef: TemplateRef<any>, private viewContainer: ViewContainerRef, ) {} ngOnDestroy() { this.viewContainer.clear(); } }

Usage in a component:

<ng-template #normal> <div>This is the normal content.</div> </ng-template> <ng-template #errorFallback> <div class="alert alert-danger">Something went wrong in this section.</div> </ng-template> <div *appErrorBoundary="hasError; fallbackTemplate: errorFallback"> <ng-container *ngTemplateOutlet="normal"></ng-container> </div>

However, catching errors in templates is tricky. A better approach is to use a component that wraps content and handles errors via ngOnInit and ErrorHandler. We can create an ErrorBoundaryComponent that uses ng-content and catches errors in its children using @Output or by subscribing to error events. But for simplicity, we'll implement a directive that toggles based on a boolean (manual error handling).

For automatic error catching, we can use Angular's ErrorHandler at the component level by overriding it for specific components, but that's not straightforward. We'll provide a component-based approach:

// shared/components/error-boundary/error-boundary.component.ts import { Component, Input, ContentChild, TemplateRef, signal } from '@angular/core'; @Component({ selector: 'app-error-boundary', standalone: true, templateUrl: './error-boundary.component.html', styleUrls: ['./error-boundary.component.scss'], }) export class ErrorBoundaryComponent { @Input() fallbackTemplate!: TemplateRef<any>; @ContentChild('content') contentTemplate!: TemplateRef<any>; error = signal<any | null>(null); catchError(error: any) { this.error.set(error); } retry() { this.error.set(null); } }

Template:

<ng-container *if="!error()"> <ng-container *ngTemplateOutlet="contentTemplate"></ng-container> </ng-container> <ng-container *if="error()"> <ng-container *ngTemplateOutlet="fallbackTemplate; context: { error: error(), retry: retry }"></ng-container> </ng-container>

But this requires manually forwarding errors. To auto‑catch, we can use a service that notifies the boundary when an error occurs in its context. This is complex. For now, we'll implement a directive that toggles on a boolean.

Given time, we'll implement an error boundary as a component that wraps content and can be used with @Output to catch errors from child components if they emit errors. But this is beyond the scope; we'll document that the developer can use the directive approach.

Objective

Implement offline detection using the browser's navigator.onLine API and the online/offline events. Notify the user when they go offline, and automatically retry failed requests when they come back online.

Business Purpose

Users should be aware of connectivity issues and not be left confused. Offline detection allows the app to inform users and even queue requests for retry later.

Technical Purpose

Create a service that listens to network status changes, stores the state in AppStateService, and provides methods to check online status. Also, implement a request queue that retries failed requests when the connection is restored.

  • RxJS for observable streams.

Dependencies

// core/services/online-status.service.ts import { Injectable, inject, signal, effect } from '@angular/core'; import { AppStateService } from '../state/app-state.service'; @Injectable({ providedIn: 'root', }) export class OnlineStatusService { private appState = inject(AppStateService); private isOnlineSignal = signal(navigator.onLine); readonly isOnline = this.isOnlineSignal.asReadonly(); constructor() { // Listen to online/offline events window.addEventListener('online', () => this.handleOnline()); window.addEventListener('offline', () => this.handleOffline()); // Update app state effect(() => { if (!this.isOnline()) { this.appState.addNotification('You are offline. Some features may be unavailable.', 'warning', 0); } else { // Optionally clear notification // this.appState.clearNotifications(); } }); } private handleOnline() { this.isOnlineSignal.set(true); // Notify user this.appState.addNotification('You are back online.', 'success'); // Trigger retry of queued requests } private handleOffline() { this.isOnlineSignal.set(false); this.appState.addNotification('You are offline. Please check your internet connection.', 'warning', 0); } checkOnline(): boolean { return this.isOnline(); } }
